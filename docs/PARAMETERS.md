# 염 스크리닝 PK 예측 — 필요한 파라미터 & 정확도 계층

신약 freebase에 대해 여러 염형태(HCl·tosylate·phosphate·esylate·oxalate …)를 만들었을 때
**어떤 형태가 in vivo 노출(AUC·Cmax)이 가장 높은지** in vitro 데이터로 예측하기 위한
입력값과, **어떤 데이터가 얼마나 정확도를 올리는지**를 정리한다.

---

## 0. 먼저 — 염이 되면 무엇이 바뀌고 무엇이 안 바뀌나? (자주 하는 오해)

| 물성 | 염형태에 따라 바뀌나? | 이유 |
|---|---|---|
| **용해도 / 용출속도 / 과포화·석출** | **✔ 바뀜 (핵심)** | 염의 결정격자·짝이온·확산층 pH가 달라짐 |
| 고체물성(흡습성·안정성·결정형) | ✔ 바뀜 | 제제·보관에 중요 |
| **막투과도 (Caco-2 Papp)** | **✗ 안 바뀜** | 용액에서 염은 **해리** → 막을 통과하는 분자는 동일한 free base/이온 평형 |
| **대사(CLint)·분포(Vss)·단백결합(PPB)·청소율** | **✗ 안 바뀜** | 모두 **용해된 활성분자(free base)**의 성질 |
| 분자량(MW) | 염은 ↑ (free base + 짝이온) | 단, **활성분자는 free base** → 모든 계산은 **free-base 환산**으로 수행 |

> 즉 염스크리닝에서 **투과·대사·분포·결합은 free base 값 1회만 측정해 공유**하고,
> **염마다 바꿔 측정해야 하는 것은 사실상 용해/용출 데이터뿐**이다. 그래서
> `AUC(염)/AUC(free base) ≈ Fa(염)/Fa(free base)` 가 성립한다.
> 근거: Serajuddin, *Adv. Drug Deliv. Rev.* 2007; FDA BCS 가이던스(투과도는 약물의 성질).

**MW 처리:** 용량은 **free base 환산 mg/kg**로 입력. 염 분말을 칭량할 때의 환산계수
(salt factor = 염MW/freeMW)는 `counterion_mw`를 주면 리포트에 표시된다. 약리·PK 계산
자체에는 free base MW만 쓰인다(활성분자 기준).

## 2. 염마다 측정하는 입력 — **정확도 계층** (용도에 맞게)

먼저 **용도 구분**(중요):
- **규제·동등성·biowaiver·QC** → **의약품동등성시험기준 다중 pH 용출(pH 1.2/4.5/6.8)**.
  두 제제가 “같은가”를 보는 **대용(surrogate)** 시험. f2≥50이면 유사. (식약처 고시 제2020-91호;
  ICH M9 / EMA biowaiver.) **허가의 표준.**
- **신약 염 스크리닝·흡수 절대예측** → 위 데이터를 GI 구획에 매핑해서 쓰거나(아래 Tier 2),
  난용성·과포화가 심하면 **생체관련/2-stage**(Tier 3)로 보강.

그리고 **평형 용해도 < 시간대별 용출**: 염의 이점인 *과포화*는 동역학 현상이라 평형값엔
안 보인다(Haloperidol: “dissolution rate … best predictor of bioavailability”).

| Tier | 입력 | 용도/무엇을 잡나 | 정확도 |
|---|---|---|---|
| **1** | 물 용해도 1점(+S0·pKa) | 메커니즘 추정·순위 스크리닝. pH·과포화 추정 | ★ |
| **2 (규제표준·권장)** | **다중 pH 용출** (pH 1.2/4.5/6.8 시간대별) | **허가 표준 + 실험실 일상 데이터.** 위(1.2)=spring, 장(6.8)=parachute로 매핑해 위→장 과포화·석출 재구성 | ★★★ |
| **3 (정밀)** | **2-stage 이행/생체관련** (FaSSGF→FaSSIF, 장 구획 용액농도-시간) | **담즙 가용화 + 과포화→석출 직접 측정.** 매우 친유성·과포화 강한 염 | ★★★★ |

### Tier 2 — 다중 pH 용출이 규제 표준이자 실용 1차 입력인 이유
실험실이 허가용으로 **반드시** 생성하는 데이터이고, 약염기의 pH 의존성(위 高·장 低)을 그대로
담는다. 본 도구는 **pH 1.2 프로파일 → 위 용출(spring), pH 6.8 프로파일 → 장 용해도 상한·재용해
속도(parachute)** 로 매핑해 2-stage 거동을 compendial 데이터만으로 근사한다.
**주의 2가지:**
1. **dose/용량-액량비 보정:** compendial은 큰 부피(예 900 mL)라 in vivo(장액 수 mL∼수십 mL)보다
   많이 녹는다. 절대 흡수로 환산할 땐 dose/fluid-volume 비를 고려해야 한다
   (*Importance of Dose/Fluid Volume Ratio*, PMC12055928).
2. **계면활성제(SLS) 주의:** SLS 함유 매질은 난용성 약물 용출을 인위적으로 부풀려 “가짜 동등성”을
   만들 수 있다 → 가능하면 무계면활성제 또는 생체관련 매질 병행.

### Tier 3 — 2-stage 이행시험이 추가로 잡는 것
약염기·염은 위(산성)에서 과포화로 녹아 장(중성)에서 **석출**한다. 흡수가 석출보다 빠른 만큼만
이득이 실현된다. 이 **과포화→석출 곡선을 직접 측정**(USP-II pH-shift / multicompartment transfer)하면
가장 정확하다. 근거: Fiolka 2018(*J Pharm Pharmacol*); *J. Pharm. Sci.* 2018,
S0022-3549(18)30683-X — *“장내 석출은 AUC가 아니라 **Cmax** 변동의 원인”* (본 검증의 Cmax 오차와 일치).

### 어떤 buffer/매질? (실무 권고)
- **규제·1차 스크리닝:** **pH 1.2 / 4.5 / 6.8** 시간대별 용출 — 최소 **pH 1.2 + 6.8**(약염기 핵심).
- **난용성·과포화 강함:** **FaSSGF→FaSSIF 2-stage(pH-shift)** 장 구획 농도-시간 곡선 추가.
- HCl 염은 **염화물 매질**에서 common-ion 억제 확인(위 용해도↓).

### 이 도구에서의 입력 방법 (Python)
- **Tier 1:** `s_salt_ugml`(+S0·pKa) → 메커니즘(공통이온·pHmax 자동).
- **Tier 2:** `ph_profiles = {1.2:[(시간h,누적분율0–1),…], 4.5:[…], 6.8:[…]}` — **다중 pH 용출(권장)**.
- **Tier 3:** `intestinal_profile = [(시간h, 용액중분율0–1), …]` — 2-stage 이행(비단조: 상승=과포화,
  하강=석출). “용출은 더 됐는데 노출 낮은”(besylate형) 현상을 데이터로 직접 반영.

## 3. BCS class별 우선순위

| BCS | 용해/투과 | 염이 도움? | Tier 권고 |
|---|---|---|---|
| **I** | 高/高 | ✗ | 염은 PK가 아니라 고체물성으로 판단 |
| **II** | 低/高 | ✔ (용출 律速) | **Tier 2 다중 pH 용출**(과포화·석출 강하면 Tier 3) |
| **III** | 高/低 | ✗ (투과 律速) | Caco-2가 상한 — 염 바꿔도 Fa 거의 불변 |
| **IV** | 低/低 | △ | Tier 2~3 + Caco-2 (용해 개선해도 투과가 상한) |

## 4. 보정 상수 (자사 reference로 1회 보정)

| 상수 | 기본값 | 의미 |
|---|---|---|
| `kd0` | 0.5 /h | free base 용출속도상수(Tier 1–3 메커니즘 모드) |
| `salt_wettability` | 4.0 | 염의 용출·젖음 이득(Tier 1–3) |
| `kprecip` | 2.0 /h | 과포화→석출 속도(Tier 1). **Tier 2는 pH6.8 곡선, Tier 3는 측정 곡선이 대체** |
| `kScale`(Caco-2→ka) | 0.30 | 자사 Caco-2 프로토콜 보정 |

**Tier 2(다중 pH) / Tier 3(2-stage) 입력을 쓰면 석출 거동이 측정값으로 들어가 보정 의존도가
줄고 정확도가 올라간다.**
